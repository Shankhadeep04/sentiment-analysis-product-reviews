
# Sentiment Analysis of Product Reviews Using NLP

## 📌 Project Overview
This project uses Natural Language Processing (NLP) to analyze customer product reviews and classify them into positive, neutral, and negative sentiments.

## 🛠️ Technologies Used
- Python
- NLTK
- Pandas and NumPy
- TF-IDF
- TensorFlow
- Matplotlib and Seaborn

## ✨ Key Features
- Text cleaning and preprocessing
- Tokenization, stop-word removal, and lemmatization
- TF-IDF feature extraction
- Sentiment classification
- Model evaluation using F1-score
- Sentiment trend visualization dashboard

## ⚙️ Project Workflow
1. Load and explore the review dataset.
2. Clean and preprocess text data.
3. Convert text into numerical features using TF-IDF.
4. Train a sentiment classification model.
5. Evaluate model performance.
6. Visualize sentiment distribution and trends.

## 📊 Results
- Dataset: 50,000+ product reviews
- Sentiment classes: Positive, Neutral, Negative
- F1-score: 88%
